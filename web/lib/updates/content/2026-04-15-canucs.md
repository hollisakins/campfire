CANUCS (the CAnadian NIRISS Unbiased Cluster Survey, PI C. Willott; Cycle 1) is
now available in CAMPFIRE — the first public program in the archive. The release
covers **1,756 NIRSpec spectra** across the Abell 370, MACS 0416, MACS 0417,
MACS 1149, and MACS 1423 lensing fields.

All spectra are uniformly reduced with the CAMPFIRE NIRSpec pipeline and carry
automated redshift estimates and quality flags.

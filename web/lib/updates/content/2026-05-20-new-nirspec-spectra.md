A new batch of reduced and visually-inspected NIRSpec spectra has been deployed
to the archive and is now available in the [catalog](/nirspec).

These spectra were processed with the current CAMPFIRE NIRSpec pipeline,
including per-source extraction for every object falling within a slitlet — not
just primary targets. As always, each spectrum carries automated redshift
estimates and quality flags from the inspection workflow.

For details on the output files and header keywords, see the
[data products reference](/docs/data-products).

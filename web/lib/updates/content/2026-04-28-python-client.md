The unified `campfire` Python package provides an API client and CLI for working
with the archive outside the web portal: query the catalog with coordinate and
metadata filters, pull individual spectra or bulk download the entire database, 
and script repeatable workflows.

To install and authenticate with your campfire login, see the [getting-started guide](/docs/api/getting-started).

Full references are available for the [Python client](/docs/api/python-client)
and the [CLI](/docs/api/cli).

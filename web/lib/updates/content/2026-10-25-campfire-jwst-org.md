The portal and API have moved to campfire-jwst.org / api.campfire-jwst.org.
Old campfire.hollisakins.com links will redirect to the new domain, so
bookmarks still work.

You will need to sign in again. If you use the Python client/CLI, you will
need to [reinstall](/docs/api/getting-started) and log in via OAuth again.

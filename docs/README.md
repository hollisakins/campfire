# docs/

Temporary design docs and plans for work in progress. Nothing here is a source
of truth: the code, its docstrings and the component `README.md` / `AGENTS.md`
files describe current behavior. When a design lands, fold whatever rationale is
still needed into the code and delete the doc.

Older design docs, audits and handoffs were removed in the 2026-11 docs cleanup;
`git log --diff-filter=D --name-only -- docs/` lists them, and
`git show <commit>^:docs/<file>` recovers one.
